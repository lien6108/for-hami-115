# 醫管資新生 AI Starter Kit

給高雄醫學大學醫務管理暨醫療資訊學系大一新生的 AI 學習工作台模板。

這不是把 AI 當成代寫工具，而是讓 AI 協助你整理課程、理解概念、完成分組任務，並逐步探索醫務管理與醫療資訊的方向。

## 如何安裝學生版 Pro-Kit

這個 Pro-Kit 是一組可攜式的 Markdown 與資料夾模板，不需要安裝 npm、Python 或其他套件。請先從 [For HAMI 115](https://github.com/lien6108/for-hami-115) 取得檔案。

### 1. 取得模板

你可以選一種方式：

- 在 GitHub 點選 **Code → Download ZIP**，解壓縮後使用。
- 如果電腦已安裝 Git，在終端機執行：

  ```bash
  git clone https://github.com/lien6108/for-hami-115.git
  ```

### 2. 複製成自己的學習工作台

找到下載內容裡的 `student-agent-kit` 資料夾，將它複製到自己的文件資料夾，並改名為例如：

```text
KMU-AI-Workspace/
```

請從這個複製出來的資料夾開始使用。不要直接修改 repo 裡的範本，也不要直接從 `For HAMI 115` 根目錄開啟 AI，因為學生版的 `AGENTS.md` 位於 `student-agent-kit` 裡面。

### 3. 用 Antigravity 開啟學習工作台（預設方式）

1. 開啟 Antigravity。
2. 選擇開啟既有資料夾／工作區。
3. 指定剛才建立的 `KMU-AI-Workspace` 資料夾。
4. 確認目前工作區名稱是 `KMU-AI-Workspace`，不是下載下來的 `For HAMI 115` 根目錄。
5. 在 Antigravity 的 Agent 對話中貼上下面的啟動提示詞。

Antigravity 是本 Starter Kit 的預設操作方式；學生不需要先使用終端機，也不需要先設定 Claude Code 或 Codex。

### 4. 其他工具（選配）

如果你已經熟悉終端機，也可以使用：

```bash
cd /你的路徑/KMU-AI-Workspace

# 依你使用的工具選一個；一般新生請優先使用 Antigravity
claude
# 或
codex
```

### 5. 完成第一次設定

1. 開啟 `000_Profile/PROFILE.md`，填入科系、年級、本學期課程與學習目標。
2. 閱讀 `AGENTS.md`，確認 AI 的學習、作業與個資安全規則。
3. 將課程資料放入 `100_Courses/`，分組資料放入 `200_Teamwork/`。
4. 在 AI 對話中貼上下面的啟動提示詞：

```text
請先讀取目前資料夾的 AGENTS.md 與 000_Profile/PROFILE.md。
這是醫務管理暨醫療資訊學系大一學生的學習工作台。
接下來請先問我：這次要處理哪一門課、目標是理解內容還是完成任務、以及老師有哪些格式要求。
請用學習教練的方式協助我，不直接代寫可繳交的作業；所有外部資訊都要標示來源與不確定性。
```

## 10 分鐘開始

完成安裝後，第一次可以先拿一份課堂講義測試：請 AI 整理「三個重點、兩個例子、一個我還不懂的問題」，再把結果存回對應課程資料夾。

## 資料夾用途

```text
000_Profile/   我的學習背景、興趣與本學期目標
100_Courses/   課程教材、筆記、作業與複習資料
200_Teamwork/  分組報告、會議紀錄、分工與專題成果
300_Campus/    社團、活動與校園資源
400_Career/    醫管／醫資探索、履歷與作品集
500_References/論文、資料來源與優良範例
900_Memory/    長期偏好、學習紀錄與踩坑經驗
```

## 常見使用情境

- 把一份講義整理成「概念、例子、我還不懂的地方」。
- 依老師的評分標準檢查報告架構，而不是直接產生報告。
- 將分組會議整理成決策、待辦與負責人。
- 比較醫務管理與醫療資訊對同一個醫療議題的不同觀點。
- 將每週學到的內容累積成未來的專題與作品集素材。

## 使用前提醒

- 不要輸入可識別病患身分的資料、病歷或實習機構機密。
- 不要把 AI 產生的內容直接當成自己的作業繳交。
- 醫療資訊、論文、統計數字與引用都要回到可靠來源複核。
- 先確認授課老師對 AI 使用與揭露的規定。

這個 Starter Kit 先提供最小可用的學習結構；Skills、自動化與 Git 備份等進階功能，等真正有需求時再加入。
