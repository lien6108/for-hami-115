# 醫管資新生 AI Starter Kit

給高雄醫學大學醫務管理暨醫療資訊學系大一新生的 AI 學習工作台模板。

這不是把 AI 當成代寫工具，而是讓 AI 協助你整理課程、理解概念、完成分組任務，並逐步探索醫務管理與醫療資訊的方向。

## 10 分鐘開始

1. 複製整個 `student-agent-kit` 資料夾，改名成自己的學習工作台。
2. 開啟 `000_Profile/PROFILE.md`，填寫基本資料與本學期課程。
3. 閱讀 `AGENTS.md`，確認 AI 的協作方式與學術誠信規則。
4. 將每門課的資料放在 `100_Courses/`，分組專題放在 `200_Teamwork/`。
5. 把下面這段提示詞貼給 AI：

```text
請先讀取目前資料夾的 AGENTS.md 與 000_Profile/PROFILE.md。
這是醫務管理暨醫療資訊學系大一學生的學習工作台。
接下來請先問我：這次要處理哪一門課、目標是理解內容還是完成任務、以及老師有哪些格式要求。
請用學習教練的方式協助我，不直接代寫可繳交的作業；所有外部資訊都要標示來源與不確定性。
```

## 資料夾用途

```text
000_Profile/   我的學習背景、興趣與本學期目標
100_Courses/   課程教材、筆記、作業與複習資料
200_Teamwork/  分組報告、會議紀錄、分工與專題成果
300_Campus/    社團、活動與校園資源
400_Career/    醫管／醫資探索、履歷與作品集
500_References/論文、資料來源與優良範例
900_Memory/    長期偏好、學習紀錄與踩坑經驗
```

## 常見使用情境

- 把一份講義整理成「概念、例子、我還不懂的地方」。
- 依老師的評分標準檢查報告架構，而不是直接產生報告。
- 將分組會議整理成決策、待辦與負責人。
- 比較醫務管理與醫療資訊對同一個醫療議題的不同觀點。
- 將每週學到的內容累積成未來的專題與作品集素材。

## 使用前提醒

- 不要輸入可識別病患身分的資料、病歷或實習機構機密。
- 不要把 AI 產生的內容直接當成自己的作業繳交。
- 醫療資訊、論文、統計數字與引用都要回到可靠來源複核。
- 先確認授課老師對 AI 使用與揭露的規定。

這個 Starter Kit 先提供最小可用的學習結構；Skills、自動化與 Git 備份等進階功能，等真正有需求時再加入。
